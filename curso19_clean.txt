Preparación GitHub Certified: Agentic AI Developer (GH-600)
DESCRIPCIÓN
Capacitación inicial de agentes de inteligencia artificial aplicados al ciclo de vida del desarrollo de software. Abarca Git y GitHub, colaboración, GitHub Actions, GitHub Copilot, instrucciones para agentes, uso de herramientas y fundamentos de Model Context Protocol (MCP), evaluación, controles de seguridad y un proyecto integrador.
OBJETIVOS
Aplicar Git, GitHub, SDLC y automatización básica con GitHub Actions en trabajo colaborativo.
Configurar agentes de codificación con GitHub Copilot, instrucciones personalizadas y fundamentos de MCP.
Evaluar y supervisar agentes mediante criterios de éxito, guardrails y revisión humana; desarrollar un proyecto integrador.

Clase 1:
Fundamentos de GitHub, SDLC e IA Agéntica
Git y GitHub: repositorios, commits, ramas, pull requests y revisión de código.
Introducción al SDLC, CI/CD y GitHub Actions.
Fundamentos de IA generativa y agentes de codificación.
Introducción a GitHub Copilot y prompting para desarrollo.
Ciclo del agente: planificar, actuar y evaluar.
GitHub como sistema de registro y plano de control.
Trabajo autónomo: práctica de repositorio, ramas y pull request.
Clase 2:
Arquitectura del Agente e Integración con el SDLC
Definición de tareas, entradas, salidas y criterios de éxito.
Separación entre planificación, razonamiento y ejecución.
Instrucciones personalizadas y agentes personalizados.
Alcance por repositorio, rama y flujo de trabajo.
Revisión, CODEOWNERS, reglas, protección de ramas y observabilidad.
Trabajo autónomo: diseño de un flujo agéntico controlado.
Clase 3:
Herramientas, MCP, Memoria, Estado y Ejecución
Uso de herramientas, APIs y permisos del agente.
Fundamentos de Model Context Protocol (MCP), servidores, registros y listas permitidas.
Contexto y límites de ejecución en GitHub.
Estrategias básicas de memoria, estado y prevención de deriva de contexto.
Manejo de errores, reintentos, reversión, escalamiento y trazabilidad.
Trabajo autónomo: laboratorio guiado de herramientas y MCP.
Clase 4:
Evaluación, Multiagente, Guardrails y Proyecto Integrador
Criterios de éxito, señales de evaluación y análisis de errores.
Ajuste de instrucciones, herramientas, contexto y permisos.
Coordinación multiagente, aislamiento, conflictos y recuperación.
Guardrails, mínimo privilegio, aprobación humana y auditoría.
Proyecto: agente que propone cambios mediante rama y pull request controlado.
Mapeo introductorio a los seis dominios del examen GH-600.
